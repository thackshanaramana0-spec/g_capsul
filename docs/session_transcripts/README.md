# session_transcripts/ — raw working transcripts, kept for provenance

These are exported Claude Code session transcripts from this project's
development. They are **not documentation** — they are the raw record of how
a decision was reached, kept per this repository's standing rule that
process evidence is archived rather than deleted.

**Do not cite anything in a transcript as a finding.** Any real result
derived from a session here has been extracted into `docs/`, `paper/`, or
`benchmark/results/` in polished, verified form. A transcript may contain
false starts, retracted hypotheses, or reasoning that was later corrected —
that is exactly why it is kept, not despite it.
