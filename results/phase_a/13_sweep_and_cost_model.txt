Fine MAXMAP sweep, and a cost model that FAILED its test

TRUE optima (10 ceilings per dataset, MINOV held fixed):

  halo   optimum MAXMAP=8   size 2,615,204   r_second 93.3%
  ecoli  optimum MAXMAP=20  size 7,857,809   r_second 89.2%
  sulfo  optimum MAXMAP=45  size 3,191,341   r_second 60.8%

Finding 1: the 4-candidate adaptive search leaves size on the table.
  ecoli  search 11 -> 7,888,285   true 20 -> 7,857,809   30,476 B left
  halo   search 11 -> 2,617,964   true  8 -> 2,615,204    2,760 B left
  sulfo  search 50 -> 3,192,415   true 45 -> 3,191,341    1,074 B left

Finding 2: the cost model does NOT predict the optimum.
  m* = L(1-r_second) * bytes_per_base / bytes_per_mismatch

  file    b/base  b/mism  ratio  L(1-r)  m* pred  m* true
  halo    0.2060  0.5765  0.357    10.1      3.6        8
  ecoli   0.2399  0.6705  0.358    16.2      5.8       20
  sulfo   0.2385  0.8774  0.272    98.4     26.7       45

  Mean relative error 55.5%, and it UNDER-predicts every time (2.2x, 3.4x,
  1.7x). Rank order is perfect (rho = 1.0 on three points) so the shape is not
  random, but the magnitude is wrong and the discrepancy itself varies 2x.

  What this rules out: the ratio term is nearly constant (0.357/0.358/0.272,
  1.3x spread), so it does NOT explain the 2.7x spread in the implied constant.
  The model is missing something structural, not miscalibrated.

  Named suspect: the derivation asserts that position and strand "cancel on both
  paths". They do not. A mapped read's position indexes the MAIN pg; an appended
  read's indexes the SECOND region. Different magnitudes, so different coding
  cost, and the asymmetry scales with r_second -- exactly the shape of the
  missing term.

No fudge factor was applied. Fitting a 2.4x correction across three points would
be curve-fitting, not a model, and it is the failure mode this project has been
explicit about avoiding. The sweep data above is the evidence base for a correct
re-derivation.

Earlier test, recorded because it was misleading: testing the same formula
against the values the ADAPTIVE SEARCH picks gave a 7.3x spread and rho = 0.536.
That test was confounded -- the search only ever chooses between two ceilings
(L/13 and L/5), so it was a continuous formula against a 2-point grid. The fine
sweep is what made the real answer visible.
